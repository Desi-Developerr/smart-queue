# Smart Queue Management System

Web-based digital queue management for hospitals, banks, government offices, colleges, and other service centers.

**Stack:** Next.js · Tailwind CSS · Supabase (Database + Auth + Realtime) · Vercel (deployment)

## Setup
1. `npm install`
2. Create a Supabase project at supabase.com
3. Run `sql/schema.sql` in Supabase SQL Editor
4. Copy `.env.local.example` to `.env.local` and add your Supabase URL + anon key
5. `npm run dev`
6. Deploy to Vercel with the same environment variables
